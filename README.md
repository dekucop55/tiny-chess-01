# Tiny Chess 4KB Engine

4KB Python chess engine for make.fun tiny-chess-01 competition.

## Run

```bash
python3 main.py
```

## Engine

Sudhan 1x configuration — alpha-beta with quiescence search, transposition table, killer moves, history heuristic, and opening book.
